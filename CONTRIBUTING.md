# Contributing

Thank you for helping improve InfoSec Feed.

1. Open an issue describing the problem or proposed source.
2. Fork the repository and create a focused branch.
3. Preserve the security-only scope, direct-source attribution and importance ranking.
4. Run Android tests and lint. For iOS changes, run the Xcode scheme tests.
5. Do not commit signing material, credentials, private feeds or copyrighted article bodies.
6. Submit a pull request explaining behaviour, tests and any publisher rate limits.

New feeds should be official or clearly attributable, use HTTPS, expose titles and
links through a documented or conventional feed format, and permit reasonable
reader access. The app stores summaries only; it is not an article-republishing service.
